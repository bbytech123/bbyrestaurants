# BBY Restaurants — GitHub Pages website

Ready-to-upload static website, exported October 29, 2026 from the final approved sandbox.

## Upload
1. Back up your existing repository and Pages/custom-domain settings first. Use a new test repository if you want to review before replacing your live website.
2. Unzip this download. Upload the **contents**, not the ZIP or an enclosing folder, to your chosen repository root. `index.html`, `.nojekyll`, and the `assets` and `fonts` folders must remain at that level. Include the hidden `.nojekyll` file. Preserve capitalization and folder structure.
3. In the repository, choose **Settings → Pages → Deploy from a branch**, select your publishing branch (commonly `main`) and **/(root)**, then Save. No npm install, build command, backend, API keys, or ChatGPT account is required.
4. Wait for the Pages deployment to succeed. Open its reported URL and check all navigation, the calculator sliders, mobile menu, contact links, and View larger graphic before switching your production domain.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Your domain
No CNAME file is included and no DNS or GitHub configuration has been changed. Preserve an existing verified CNAME/settings when replacing an already-connected site. Do not overwrite unrelated DNS records.
